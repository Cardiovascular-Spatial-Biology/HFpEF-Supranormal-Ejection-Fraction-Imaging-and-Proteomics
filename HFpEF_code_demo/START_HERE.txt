
HFpEF imaging and proteomics

1. Open HFpEF_code_demo.Rproj in RStudio.
2. Install missing packages once: source("install_dependencies.R")
3. Run in a fresh R session: source("run_all.R")

Installation requires internet access. The analysis runs offline.
Inputs: data/synthetic/
Outputs: results/demo/ (later runs use a timestamped folder)

All supplied data are synthetic. Demo outputs are not the study results.
See README.md for the script list, terminal commands and data formats.
