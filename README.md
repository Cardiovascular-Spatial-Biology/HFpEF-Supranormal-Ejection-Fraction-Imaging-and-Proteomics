# hfpef-supranormal-ejection-fraction-imaging-and-proteomics
Imaging and plasma proteomics analyses characterizing exercise responses in HFpEF with supranormal ejection fraction, linking cardiovascular physiology to circulating molecular signatures.

## Analysis code and synthetic demonstration

The runnable R workflow, synthetic input matrices and documentation are in [HFpEF_code_demo](HFpEF_code_demo/).

Start with the [README and run instructions](HFpEF_code_demo/README.md). The workflow includes Fig 4d pathway enrichment and Table S14 medication sensitivity. All participant records, expression values and reference annotations supplied within that folder are synthetic. Demonstration outputs are not the study's numerical results; the documentation identifies reconstructed analyses and their limitations.
